# Preview assets / 演示素材

chatgpt.gif, claude.gif and deepseek.gif are real browser recordings from a separately prepared brand-particle showcase, after its introduction animation finished. Each preview is approximately six seconds at 960 × 540 pixels. No renderer implementation or brand animation preset is distributed through these files.

These demonstrations use an external runtime and additional brand-specific shape/animation work. They are illustrative project results, not out-of-the-box outputs promised by the public conversion toolkit. In particular, the OpenAI/ChatGPT intertwined-path example and the Claude deformation use capabilities outside the public closed-path converter.
